Project Overview

FIS Java Portfolio is a web application developed to showcase my Java backend development work in one professional online portfolio. It provides a central place for recruiters and employers to learn about my projects, the technologies I use, and the skills I am developing.

The website includes a homepage and dedicated project details pages for JobConnect, Fountain Verify, and this portfolio application. It is being developed with a focus on clear navigation, professional presentation, and responsive design.

Key Features

Project Showcase

Presents my Java projects with descriptions, technologies, and dedicated details pages.

Spring MVC Routing

Uses Spring Boot controllers to map web addresses to the appropriate pages.

Thymeleaf Templates

Uses server-rendered HTML templates to organize and deliver the website's pages.

Responsive Design

Uses CSS layouts and media queries to adapt content to desktop, tablet, and mobile screens.

Professional Presentation

Uses a consistent navy-blue, white, and gold visual identity across the portfolio.

Recruiter-Focused Layout

Organizes project information so visitors can quickly understand my work and technical interests.

Technologies Used

The portfolio is being built with the following technologies:

Java Spring Boot Spring MVC Thymeleaf HTML5 CSS3 Responsive Design

What I Practised

Building this website has helped me practise creating Spring Boot controllers, mapping URLs, organizing Thymeleaf templates, structuring HTML pages, applying responsive CSS, and connecting navigation links across multiple pages.

It also demonstrates my ability to document and present software projects in a clear, recruiter-friendly format.
